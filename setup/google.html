Connect UM Spec to Google

ZIP works immediately. The developer must configure a public Google OAuth client ID before distributing the Google-connected version.

  1. In Google Cloud, create or select a project. Enable the Google Drive API and Google Calendar API.
  2. Configure Google Auth branding, support contact, privacy-policy URL and an external test audience. Add consenting test accounts.
  3. Load UM Spec in Chrome's Extensions page. Create an OAuth client of type Chrome Extension and register the extension's exact ID. A Web Store release must use its production extension ID.
  4. From the repository, run node scripts/configure_google_oauth.cjs followed by your actual public client ID. If using a stable development extension key, pass --extension-key followed by the public key and register the resulting ID.
  5. Reload the extension, refresh Spectrum, open the exporter and select your courses. Click Connect Drive or Connect Calendar in the popup.
  6. Complete the live test checklist in the repository before broad release. Complete Google's consent publishing and verification requirements for the selected scopes.

Never put a client secret, Google password or Spectrum cookie in the extension. The OAuth client ID and extension public key are public configuration.

Drive access covers files UM Spec creates. Calendar access manages a dedicated UM Spec calendar and reads calendar names/IDs to recover it. It does not grant access to events on unrelated calendars.

Automatic checks run while Spectrum is open and signed in. Uncertain announcement dates require review.
